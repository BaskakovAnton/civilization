# Политика источников

## Типы (`type`)

| type | Пример |
|------|--------|
| `canon_text` | Книги еврейской Библии / НЗ как текстовые свидетельства |
| `historical_document` | 1–2 Макк., др. исторические повествования |
| `inscription` | Мернептах, Тель Дан |
| `archaeology` | Поселения Iron I, стратиграфия |
| `classical_historiography` | Иосиф, Дион Кассий, Тацит |
| `modern_handbook` | Вводный академический консенсус (ориентир каркаса) |

## 1–2 Маккавейские (утверждено)

- id: `1_macc`, `2_macc`
- type: `historical_document`
- UI: указать, что вне еврейского Танаха; у католиков — второканон.; в православии обычно неканон. для чтения

## Иосиф

- `josephus_antiquities`, `josephus_war`
- Использовать с эпохи `roman_herodian` по `war_and_divergence`

## Эпиграфика (якоря MVP)

- `merneptah_stele`
- `tel_dan_inscription`

Полный корпус надписей не требуется на MVP.

## Citations (P6)

Предпочтительны прямые `url` на:

- стихи — BibleGateway NRSVUE (или эквивалент)
- надписи — стабильные энциклопедические статьи / музейные страницы
- Иосиф — обзорные статьи с ясной привязкой к эпизоду

`source_ids` остаются обязательными; `citations` — уточнение «куда кликнуть».
