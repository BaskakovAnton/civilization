# Методология (MVP)

Проект **civilization** — интерактивный историко-критический каркас длинной дуги ВЗ/НЗ.

## Тон

Университетский textbook-консенсус (вводный handbook). Конкурирующие школы — отдельный этап.

## Язык

- UI и формулировки claims — **русский**
- Id эпох, источников, claims — **английский** `snake_case`

## Слои знания

1. **Epoch** — 12 эпох каркаса
2. **Claim** — проверяемое утверждение с `confidence` и источниками
3. **Interaction** — типизированное ребро между лицами + источники
4. **Source** — реестр исходников
5. **Candidate person** — curated лица (не attested history)

Нарратив Писания не равен истории: библейский сюжет без внешней опоры → `literary` или `disputed`.

## Иосиф и отцы

- Иосиф Флавий — точечно, эпохи 8–11
- Отцы Церкви — вне MVP

## Маккавеи

`1_macc` / `2_macc` = `historical_document` для эпохи `hellenistic_hasmonean`, не «канон пользователя» в UI.

## Вне скоупа MVP

Theographic full ingest, Strong’s, RAG, линзы школ, отцы Церкви.
